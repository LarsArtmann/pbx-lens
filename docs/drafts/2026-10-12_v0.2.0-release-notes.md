## Draft release notes

# v0.2.0 — pbx-lens

The wire-and-UI release: every page answers conditional GETs with 304s and
Server-Timing, the UI is rebuilt on templ-components to the hilt, and the
detail page turns a search hit into a jump straight to the transcript
evidence.

## What changed

- **HTTP stack.** Conditional GET everywhere (go-etag): unchanged pages, htmx
  poll fragments, and static assets answer 304 Not Modified; a skip policy
  keeps the unbounded export/recording streams and the ever-changing
  staleness/freshness bodies out of the buffer. Server-Timing on every route,
  gzip compression ordered outside the ETag so tags hash identity bodies,
  `GET /version` and a Prometheus `/metrics` surface, and the stream-contract
  fix (`WriteTimeout: NoTimeout`) that stops the 30s appkit default deadline
  from truncating no-row-cap exports and long recording downloads. Page
  renders are buffered into one atomic write — a flushed body can never be
  hashed into a 304, and a mid-render failure is a real 500.
- **UI pass (templ-components v1.21.0).** Library forms + buttons replace
  every hand-rolled filter control; Container/Split/Stack replace page
  wrappers; transcripts render as a terminal-style Scrollback; the AI/human
  mix is a PieChart donut with exact counts; the dashboard gains a
  weekday×hour density heatmap, 7/30-day window presets, and delta chips.
- **Detail-page operator affordances.** Copy-to-clipboard on the native id
  and both phone numbers (CSP-safe, no inline JS); the search deep link
  carries `?q=` into the detail page, marks matching transcript turns amber,
  and redirects once to the first match's anchor (`?q=…&at=N#turn-N`) — the
  jump works without JavaScript; breadcrumbs; print styles.
- **Golden-HTML regression net.** The operator pages are pinned by `.golden`
  snapshots (refresh = `-update` + reviewed diff), a palette gate bans raw
  blue in pbx-lens templates (one teal theme bridge owns color), and a
  templ-generate sync test keeps codegen honest.
- **Ops.** `/api/ops` gained the response-cache section (`etag_generated`,
  `not_modified`, `hit_ratio`, `buffer_overflows`; overflow warns
  immediately). The backup restore drill (VACUUM INTO snapshot → integrity
  verify → restore → FTS rebuild) runs as its own named CI lane on every
  push.
- **DID-interception direction auto-detect.** `-ai-did` on `ingest-telnyx`
  and `serve`: conversations touching a configured AI DID index as inbound
  regardless of the declared poll direction. Empty flag = old behavior.
- **Honesty and speed fixes (2026-10-15).** The nav shell's random id made
  every page body unique, so the ETag/no-cache contract never answered 304 —
  pages now pin a deterministic id and revalidate for real (a regression
  test guards it). An empty window no longer renders zero-height chart
  boxes pretending to be data. Every HTML response carries an explicit
  `Content-Length` (pages far over Go's 2 KiB implicit buffer shipped
  chunked). New `/ops` page: ingest, retention, and cache health at a
  glance, with `last_pass_age_seconds` on the API so monitors can catch a
  silently stopped poller. `robots.txt` + noindex everywhere, an explicit
  recording-stream rate limit (loopback exempt), and an opt-in CSP
  report-only dry run (`CSP_REPORT_ONLY=1`). UI trio bumped (go-appkit
  v0.9.0, templ-components v1.23.0; go floor 1.27.2).
- **Fixed.** AI-assistant recordings play again: Telnyx stores these MP3-only
  (live-verified 2026-10-12), so the proxy fell back from a hard WAV
  requirement to WAV-preferred/MP3-fallback. The golden suite's wall-clock
  scrubber no longer lets relative times flake the tests.

## Upgrade notes

Single binary, disposable index — pull and rebuild; no migration. New flags
are opt-in (`-ai-did` empty by default). `httputil` v1.4.1,
`httputil/server_timing` v1.0.2, `go-etag/server` v0.6.1 promoted to direct
dependencies (all three were already in the module graph via go-appkit).
