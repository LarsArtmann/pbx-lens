## Body A — v0.2.1 (patch: fixes + integrity only)

```markdown
## v0.2.1 — gate truth and test integrity

A hardening release: no new operator-facing features. Every change makes
the existing surface more trustworthy — gates that prove themselves red,
tests that pin contracts that were only ever hoped, and six CI-red lint
findings fixed at root.

### Fixed

- Six lint findings that had reddened main CI, fixed at root where
  possible: the segment cost rate now divides by the domain-owned
  `calls.MicrosPerUnit`, the quality-trend seed builds by append, the
  trend sum returns unnamed values, and the two optional-result `nil`
  returns carry reasoned suppressions.
- styles.css regenerated by the pinned nix builder (the analytics
  utilities of the previous release had shipped without their CSS).
- The dashboard's freshness pill no longer fights HTTP caching
  (ETag-vs-liveness tradeoff resolved owner-side).
- docs/http-stack.md no longer claims phantom tests: the recording
  proxy's two-hop timing contract is pinned by a real test, and the
  doc's never-written slow-upstream test name is corrected to the
  fast-fail pair that actually holds the claim.

### Test and gate integrity

- The committed Tailwind class corpus is freshness-tested (pin stamp vs
  go.mod, a line floor, and a rendered-class census), with seeded-red
  proofs for every failure mode.
- CI runs the guard scripts' own red paths: the four `--self-test`
  gates plus the docs truth gates on every push.
- The property oracle drives full call lifecycles (record, correct,
  enrich, retire) with per-act convergence; the retire path has its own
  payload golden; `LookupView`'s two-key-generation contract is pinned
  end to end; memory↔sqlite deployments are proven observationally
  equivalent.
- New doc gate: every backticked `Test…` name in the living docs must be
  a real test in the tree (the gate's first run caught 8 phantoms).

### Internal

- `nix develop -c bash scripts/poll-gate.sh -- … buildflow --build-mode
  dev` is the gate entry point; the first calm-window FULL receipt is
  recorded.
```

**CHANGELOG mechanics for A:** move ONLY the `Fixed` sections + the
test-integrity/gate sections under a new `## [v0.2.1]`; everything
user-facing (catalog, analytics, spend/segments/quality cards, anomaly
baseline, firstpage metric, templ-components bump) STAYS under
`Unreleased` for the next minor.

## Body B — v0.3.0 (minor: everything since v0.2.0)

```markdown
## v0.3.0 — the analytics surface

Two days of north-star work: the dashboard became an analytics surface,
the eventcatalog grew the real topology, and the test depth caught up to
the feature depth.

### Analytics (read-only, denominator-honest)

- Spend card: mean cost per billed minute over PRICED calls only; mixed
  currencies refuse to sum; week-over-week delta.
- Segment tables: top PBX-side numbers and outside parties with AI share,
  average duration, and per-segment cost rate; every row deep-links into
  the filtered list via `?number=`.
- Quality: hangup causes, no-user-turn share with a week-over-week trend
  in percentage points, per-call truth signals (no user turn, self-dial,
  recording tail).
- Anomaly baseline: the density heatmap carries a weekday note — today
  against that weekday's usual ±2σ band, silent until two weeks of
  history.
- Counterpart history on the call detail page.
- CDR calls derive direction from the PBX sides; the export streams and
  the recording proxy carry Server-Timing (`firstpage` names the
  time-to-first-row; the recording names both upstream hops).

### Catalog and search

- The federated eventcatalog renders the real topology: FreeSWITCH and
  Telnyx as read-only external systems, the call-index service with its
  read/write edges, the receiver webhook as a source container.
- FTS5 search over transcripts and phone digits, with the match log and
  deep links into the transcript.

### Platform

- templ-components v1.24.0 with one formatting dialect; lint at zero.
- go-cqrs-lite wave: systemscenario-backed end-to-end and chaos tests,
  the golden payload trail, optimistic-concurrency and delayed-sqlite
  proofs.
- Ingest hardening: `-dry-run` everywhere, `-max-age` retention gating,
  the `refresh` backfill classifier.

### Fixed

- (the six CI lint findings, the styles.css regen, the freshness-pill
  tradeoff, the phantom-test doc correction — same list as body A)
```

**CHANGELOG mechanics for B:** rename `## [Unreleased]` to
`## [v0.3.0] — 2026-10-25` (everything ships together); no split needed.

## How to execute either (after the owner picks)

1. Apply the CHANGELOG mechanics above; commit.
2. `bash scripts/cut-release.sh v0.2.1` (or v0.3.0) — the script enforces
   clean tree, HEAD==origin, calm load, green full gate, green remote CI
   before tagging.
3. Paste the chosen body into the GitHub release the script's tag creates.
