# v0.1.0 — pbx-lens

First tagged release. pbx-lens is a unified call-history index for
pbx.artmann.tech: one queryable browser UI over every telephony source we
already have — FreeSWITCH CDR CSVs, the Telnyx conversations/recordings
APIs, the receiver webhook JSONL, and agent transcripts — without ever
writing back to a source.

## What is in it

- **Ingest with replay semantics.** Every source row becomes an `Observation`
  with a deterministic stream id (`<kind>:<native-id>`), so re-ingesting the
  same file is a no-op, not a duplicate. The CDR parser handles vanilla
  mod_cdr_csv output (the `,"", "` bare-quote tail Go's strict CSV rejects)
  — caught live against a real FreeSWITCH, pinned by a regression test.
- **Browser UI.** Calls list with FTS5 ranked search plus partial phone-number
  search (any 4+ digit run), a Europe/Berlin dashboard with 30-day volume,
  duration histogram, and week-over-week deltas, htmx auto-refresh (30 s
  cards, 60 s staleness; self-hosted runtime, server-rendered no-JS
  fallback).
- **Streaming exports.** `/api/export.jsonl` and `/api/export.csv` walk the
  index keyset-paginated with bounded memory; both answer with an explicit
  `X-PII-Mode` header. Raw-at-rest is owner doctrine — the export gate is
  the PII boundary.
- **Ops.** htpasswd auth with SIGHUP reload and per-address failed-login
  throttling, structured `log/slog` records, `GET /api/ops` per-source
  counters, `VACUUM INTO` snapshots with an integrity-checked restore drill
  (a checked-in test), and a `purge` command with JSON dry-run reports.
- **Nix all the way down.** Hermetic flake build, a NixOS module
  (`services.telephony.pbx-lens`, in nix-international-telephony) with
  backup + purge timers, systemd Type=notify, and LoadCredential for the
  Telnyx key and htpasswd.

## Try it

```console
nix run github:LarsArtmann/pbx-lens -- version
nix run github:LarsArtmann/pbx-lens -- serve -db /tmp/lens.db -addr 127.0.0.1:8300
```

## Honest scope

v0.x on purpose. The index DB is disposable and always re-derivable from the
sources; the app is a single binary with no external Go consumers yet.
CQRS/event-sourced core (go-cqrs-lite `system` composition root), sqlite via
modernc (pure Go, no cgo), 14 test packages, race-clean, full BuildFlow gate
green at tag time.
