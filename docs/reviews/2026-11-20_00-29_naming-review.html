00Summary

The vocabulary is in the best shape of the three naming passes: zero lying names, zero Manager/Handler/Impl/Util trash cans, zero negative or noun-shaped booleans, and a verb grammar (Fetch / List / Lookup / Map / Parse / *Query) that a repo-wide grep survey confirms has no synonym drift. All eight findings sit at the seams the codebase grew since 2026-10-11 — the enrichment seed's row key, the retention reason's type boundary, and the web analytics vocabulary the DOMAIN_LANGUAGE.md core table never absorbed.

The bottom line Nothing blocks anything. The one finding worth acting on first is EnrichmentSeed.StreamKey: the field name says “stream key” but the value it holds is a calls.RecordKey() string — the name hides which string it is in exactly the place a zero value is silently dropped. Renaming it (or adopting the branded StreamKey type today's data-model review proposes) is a compile-checked, hash-safe Go-identifier move.
