00Current State

Every production file was read this session (the 2026-10-11 naming review covered the vocabulary; this review covers the shapes). The model's backbone is deliberately disciplined: branded identity strings, validation at the construction boundary, zero-value-as-absent instead of pointer state, and a read model that denormalizes with a tested round-trip invariant. Most "findings" a generic review would raise here are documented doctrine, not rot. The real defects were at the seams — and two of them are fixed in this pass.

01Problem Catalog

Fixed in this pass

Search hits carried raw-string identity

internal/search/search.go:41

Hit.Kind and Hit.NativeID were plain strings while the domain owns SourceKind and NativeID — swapping the two fields at a call site compiled, and the deep-link builder trusted the order.

Fix Typed both fields with the domain types (fixed in this pass; tests green). A Kind/NativeID swap is now a compile error.
Fixed in this pass

The excerpt ceiling was owned by one mapper, not the domain

internal/ingest/agent/agent.go:199 · internal/ingest/telnyx/map.go:11

Telnyx capped TranscriptExcerpt at 200 runes; the agent mapper shipped the first turn uncapped. A long AI opening line flowed into the read model and into the list page's single table cell. Two sources, two silent shapes for one domain field.

Fix The bound moved into the domain (calls.DefaultExcerptMax = 200 — the domain owns its field's shape), the Telnyx constant aliases it, and the agent mapper now caps with a regression test. Existing agent rows re-derive on next ingest (disposable-DB doctrine absorbs the one-time correction wave).
Accepted risk — documented

ContentHash concatenation can alias crafted field pairs

internal/calls/domain.go:128-142

The hash joins fields with \n separators and no length prefix. Free-text fields (transcript excerpts can contain newlines) plus source-supplied party strings could in principle be crafted so two different observations render the same hash input — aliased streams, silently dropped corrections. For this deployment the sources are the operator's own files and the operator's own Telnyx account, so the attack surface is the operator. Accepted — but the format is now frozen at schema v1 precisely because it cannot be changed casually (every stored hash would shift).

Forward fix (v2) Length-prefixed field encoding in the hash, gated behind schema version 2 with an upcaster; the one-time correction wave on re-poll is a supported operation (the index is re-derivable).
Deliberate doctrine — verified, not rot

Raw-as-observed participants

internal/calls/domain.go:95-114

FromNumber/ToNumber are raw strings although E164/ParticipantHash exist. Real CDRs carry unknown and garbled parties; enforcing E.164 at storage would reject honest source rows. The typed pair is load-bearing exactly where the policy lives: the ?pii=hash export validates-then-hashes, and unparseable parties render as an honest [redacted] marker instead of a fake number.

Deliberate doctrine — verified, not rot

Zero-value-as-absent, never pointer state

internal/calls/domain.go (MOS, Enrichment) · internal/web/queries.go (AI *bool)

MOS 0 = not reported (omitted from JSON and hash), zero Enrichment = nothing fetched yet, and the list filter's AI *bool nil = unset. The review actively endorses the absence of *float64/*string optionality here: the codebase documents each zero's meaning at the field, and the hash covers the value fields only so re-polls stay idempotent. The one tri-state pointer is the correct Go idiom for nil-as-unset, not a pointer minefield.

Ready-when-touched

TranscriptTurn.Role is a plain string

internal/calls/domain.go:89-93

The role vocabulary is a closed two-value union (user/assistant) normalized at both mappers, but the domain field accepts any string. A TurnRole named string with two constants would make an invalid role unrepresentable — and is hash-compatible today (%s prints the same bytes), so it can land whenever the file is next touched for real reasons. Deferred as pure churn right now.

02The Vision

1
Boundaries own their invariantsThe domain owns the excerpt ceiling, the hash recipe, and the stream-id format; mappers and the UI adapt to it, never the reverse.
2
Closed vocabularies are typesSourceKind, Direction, and (when touched) TurnRole make invalid values compile errors, not runtime rejections.
3
Zero means zero, documentedEvery zero value that means "absent" says so in a comment and stays out of ContentHash; no pointer state anywhere in the domain.
4
Read-model denormalization with round-trip proofsCallView duplicates the observation deliberately, and ViewFrom/Observation() are lossless inverses — an invariant the enrich pass leans on.
5
Wire tolerance isolated at the perimeterFlexTime, DetailRecord's dual spellings, and metadata-as-any live only in ingest adapters; the domain never sees a dialect.
6
Identity is deterministicStream id = kind:native-id, hash equality = observation equality; re-ingest is the same stream and replay emits zero events.

03Go Data Model

The core that everything else serves, with the invariants annotated:

// Identity is branded, not stringly: swapping kinds for ids cannot compile.
type SourceKind string   // freeswitch-cdr | telnyx-conversation | webhook-log | agent-transcript
type NativeID string     // the source's own row id; never invented by the lens
type E164 string         // Valid() enforces +digits; Hash() feeds the PII export

// One source row. Validate() is the gate every parser passes through;
// zero MOS means "not reported" and stays out of the hash.
type Observation struct {
    NativeID          NativeID
    Kind              SourceKind
    Direction         Direction
    StartedAt         time.Time
    DurationSecs      int
    FromNumber, ToNumber string   // raw as observed; E164 policy applies at export
    HangupCause       string
    IsAI              bool
    TranscriptExcerpt string       // capped by the domain's DefaultExcerptMax
    Transcript        []TranscriptTurn
    RecordingRef      string
    MOS               float64       // 0 = not reported, omitted from JSON + hash
}

// Derived data that never mutates observation identity: it refreshes
// independently and rides the full-recompute folds.
type Enrichment struct {
    CostMicros     int64   // 0 = no cost reported
    CostCurrency   string
    InsightSummary string
}

// The read-model row: observation + enrichment + the hash that proves it.
// ViewFrom and v.Observation() are lossless inverses (tested).
type CallView struct {
    // ...every observation field, plus:
    CostMicros     int64
    InsightSummary string
    ContentHash    string  // equality of hashes IS equality of observations
}

05Validation Layer

Invalid observations cannot enter the index: every parser ends in obs.Validate(), every command constructor (NewRecordCommand, NewEnrichCommand, NewRetireCommand) re-validates before addressing a stream, and every rejection carries a stable error code (call.record.unknown_source_kind, call.record.negative_duration, …). The four .Valid() predicates make the closed vocabularies checkable at the boundary. What the model deliberately does not do is hide its fields behind an unexported-field constructor: the event store serializes payloads as JSON, so the validation gate lives exactly where the writers live.

07Anti-Patterns

Do not change the hash recipe casually

ContentHash equality IS observation equality. A "small" format tweak re-writes every stored hash and turns the next re-poll into a full correction wave. Gate format changes behind schema v2.

Do not hand-assemble projection record keys

The StreamMarker: prefix is the library's business. Derive keys via obs.StreamID().String() — the hand-built variant was this session's highest-value fix (cli/agent.go).

Do not pair create folds with update folds

metaengine routes a first event through the update fold with a zero prev and stores a zero view. Full-recompute views ship create folds only (documented gotcha, verified in projection.go).

Do not let a source own a domain field's shape

The excerpt ceiling belonged to one mapper and silently didn't apply to another. Bounds on domain fields live in the domain; mappers reference them.
