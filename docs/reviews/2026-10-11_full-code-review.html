02Findings & Strengths

Recording proxy has no upstream timeout

proxyTelnyxRecording fetches metadata and streams audio via http.DefaultClient (no timeout); the Telnyx client likewise. Request contexts cancel on browser disconnect, but a stalled CDN connection holds a handler goroutine indefinitely. Ticketed — the right bound (whole transfer vs. metadata-only) is a product decision about the longest legitimate recording.

web imports a source adapter concretely

web.RecordingOptions.Telnyx is *telnyx.Client, while the same Options struct already defines a consumer-side Searcher interface for search. A RecordingFetcher interface would match the established pattern — ticketed as optional polish; with no second implementation the interface buys nothing today (YAGNI respected, noted for the next touch).

Export streams swallow mid-stream write errors

exportJSONL/exportCSV return silently if a marshal/write fails mid-stream. Acceptable: CallView always marshals, headers are already sent, and a truncated download is visible to any consumer. Noted, not ticketed.

CallState.RetireReason is write-only today

The fold records why a stream was retired but nothing reads it yet — fold-completeness for future audit queries ("why is this call gone from the index?"). Deliberate; keep.

03Modularize Verdict

HOLD: single module — no split, no merge

Scored per the go-modularize signal table: small project (10 internal packages, one domain) High, no external consumers High (the sibling telephony repo gets a NixOS module, not a Go import), prototype no, all-change-together no. Direction-neutrality test: a boundary earns its keep only when some consumer imports one side without the other — with zero consumers, every candidate seam earns nothing. The import graph is already a clean DAG with textbook layering; a go.mod line would encode a boundary the packages already enforce.

Revisit triggers: (1) a second aggregate lands (E003 decided 2026-10-11: hold flat, the write/read seam calls/callviews pre-agreed — see AGENTS.md), (2) an external Go consumer appears, (3) CI time from the single module becomes measurable.
