The bottom line

Two gaps hold the whole fleet score down — both are one-day fixes.
  1. go-error-family is used at the origin but ignored at the boundaries (45/100). CLI exit codes, HTTP status mapping, structured logging, and the test-assertion package are all hand-rolled instead — ~7 duplication sites across cmd/pbx-lens/main.go:89-92 and 14 web call sites.
  2. The hand-rolled Server-Timing middleware rests on a factually false doctrine. “No middleware constructor in any release” is wrong — ServerTimingMiddleware() has shipped since v1.0.1 (verified in the module cache at v1.0.1, v1.0.2, v1.0.3). The claim lives in internal/web/timing.go:16-17, docs/http-stack.md:32-34, and AGENTS.md (corrected 2026-11-04 by this audit).

Everything else is health: the backbone — go-cqrs-lite runtime core (92/100) and templ-components (93/100) — is at reference quality with every paid-for library contract fenced by a named guard or test; the HTTP stack is current and doctrinally documented; and every one of the twelve not-imported verdicts is a documented decision (domain mismatch, a rejected prerequisite like samber/do, or the R9 no-SSE polling doctrine), not neglect. Notably, all seven used pins are the latest releases — the 2026-10-24/25 sweep and the v1.26.0 bump left zero version debt.

Findings, highest impact first

Missed Opportunity · false doctrine

Hand-rolled Server-Timing middleware duplicates a constructor that has existed since v1.0.1

internal/web/timing.go:16-25 · docs/http-stack.md:32-34 · AGENTS.md (corrected) · prior audit finding #2

ServerTimingMiddleware() and ServerTimingMiddlewareWhen(pred) are present in the module cache at v1.0.1 (server_timing.go:405), v1.0.2, and the pin v1.0.3 (server_timing.go:400,416). The hand-rolled wrapper diverges: it does not propagate r.Pattern and stamps headers on every route, including unauthenticated runs — upstream’s When variant is the documented gate. Three documents assert the constructor does not exist; any future session reading them will preserve or “restore” the duplicate.

Recommendation Swap to the library middleware and fix all three stale texts in one commit; evaluate ...When(pred) gating. 
// before: internal/web/timing.go (hand-rolled, divergent)
func ServerTimingMiddleware() httputil.Middleware { /* WrapServerTiming wrap */ }

// after: cmd/pbx-lens/serve.go (library-owned)
ExtraMiddlewares: []func(http.Handler) http.Handler{
    auth, securityHeaders, servertiming.ServerTimingMiddleware(), compression, etagMW,
}
Missed Opportunity · high operator value

CLI exits 1 for everything; the library maps families to sysexits + What/Why/Fix

cmd/pbx-lens/main.go:89-92 · cmd/pbx-lens/ops.go:99 · internal/cli/system.go:58

fatal() always os.Exit(1). The library’s ExitCode(err) maps the already-constructed NewTransient("lens.cli.projection_timeout") to exit 75 (EX_TEMPFAIL) — scriptable — and HandleError(err) adds What/Why/Fix messaging for free. ~10 lines deleted, operator semantics gained.

Recommendation Route the CLI through HandleError/ ExitCode. Caveat: family defaults are fail-open (unknown → Transient → 75) — keep the poller’s documented reasoning comments. 
// before
func fatal(err error) { fmt.Fprintln(os.Stderr, "pbx-lens:", err); os.Exit(1) }

// after
errorfamily.HandleError(err) // What/Why/Fix + os.Exit(family.ExitCode)

internal/web/ops.go:296-298 · internal/web/ops.templ:205-206 · ops_page_test.go:172-189

Recommendation Swap to EmptyText: "never", delete the guard branch, slim the tests to a pin test; refresh the filings ledger + adoption map.
Missed Opportunity · removes a leak surface

Fourteen web sites hand-map families to HTTP statuses and write err.Error() inline

internal/web/server.go:182,193,354,500,507,555,618-626,632 · export.go:176,192 · search.go:50-55,67 · freshness.go:31,43 · segment_page.go:31 · recording.go:111,235

Recommendation Adopt errorfamily.HTTPHandler for the JSON/HTML error paths; classify the three bare 503s with WrapInfrastructure (catalog.go:33 already models it).

Missed Opportunity · fits a planned TODO exactly

projectionhost.Reset is the planned legacy-key rebuild, already built upstream

never called · target: docs/gotchas.md record-key entry · projectionadapter Resettable present at pin

The planned one-time read-model rebuild that retires legacy marker-prefixed keys currently means “drop the file and re-poll every source”. Recommendation Use Reset when executing the rebuild TODO instead of drop-and-repoll.
